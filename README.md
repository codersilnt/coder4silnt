# CODER4SILNT

Modular CLI reconnaissance, OSINT, local network peer discovery, and non-intrusive security posture auditing suite.

## Features
- **[1] OSINT URL & Social Scan**
- **[2] Phone Number Audit**
- **[3] Email Audit**
- **[4] Full Comprehensive Scan**
- **[5] Deep Posture & APK Audit** (non-intrusive configuration posture & static APK archive summary)
- **[6] Local Wi-Fi / Hotspot Audit** (local network device discovery & risk posture summary)

## Usage
```bash
chmod +x coder4silnt.py
python3 coder4silnt.py
```

Or run via symlink:
```bash
coder4silnt
```

## Responsible Use Notice
All posture and network checks are non-intrusive and intended strictly for authorized security assessments, auditing, and educational research.
