# Changelog

All notable changes to **CODER4SILNT** are documented in this file.

## [1.0.0] - 2026-11-24
### Added
- Modular CLI interface with mobile-aligned ASCII banner and ANSI color support.
- Core scan menu options `[1]` through `[6]` covering OSINT, phone/email auditing, posture checks, APK archive inspection, and local network discovery.
- `save_audit_report` and `inspect_apk_summary` helpers wired into interactive options `[5]` and `[6]`.
- Portable relative `./reports` output directory for JSON and TXT audit summaries.
